# Recursion

Рекурсивные методы `Rec.DigitSum(int n)` и `Rec.Pow(int x, int n)` без циклов и `Math.Pow`. Базовые случаи отмечены комментариями.

Запуск из каталога проекта при установленном .NET SDK 8 или новее:

```text
dotnet run
```

Ожидаемый вывод:

```text
DigitSum(0) = 0
DigitSum(7) = 7
DigitSum(12345) = 15
DigitSum(1000) = 1
Pow(2, 0) = 1
Pow(2, 10) = 1024
Pow(5, 3) = 125
Pow(7, 1) = 7
```

Отрицательный аргумент `n` отклоняется. При переполнении `long` метод `Pow` выбрасывает `OverflowException`. Значение `Pow(0, 0)` по принятому базовому случаю равно 1.
