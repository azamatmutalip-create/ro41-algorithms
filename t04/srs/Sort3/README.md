# СРС 4. Сортировка трёх чисел через ref

Класс Order содержит методы Swap(ref int x, ref int y) и Sort3(ref int a, ref int b, ref int c). Массивы не используются.

Swap меняет значения с помощью временной переменной. Sort3 сравнивает пары (a, b), (b, c), (a, b) и изменяет аргументы только вызовами Swap. После второго сравнения c содержит максимальное значение, последнее сравнение упорядочивает a и b. Параметры ref позволяют изменить переменные вызывающего кода.

Запуск из корня репозитория (.NET SDK 8 или новее):

```bash
dotnet run --project t04/srs/Sort3/Sort3.csproj
```

Программа автоматически проверяет все пять троек, ввод с клавиатуры не нужен.

Ожидаемый вывод, записанный до запуска:

```text
3 1 2 -> 1 2 3
1 2 3 -> 1 2 3
3 2 1 -> 1 2 3
2 2 1 -> 1 2 2
5 5 5 -> 5 5 5
```
