# Трассировка операций со строками

## 1. `Trim()` и `Split(';')`

```csharp
string s = "\u00A0 Ахметов Ерлан;85 ";
string trimmed = s.Trim();
string[] parts = trimmed.Split(';');
```

`Trim()` убирает неразрывный и обычный пробелы в начале и пробел в конце. Результат — `"Ахметов Ерлан;85"`. Пробел между фамилией и именем сохраняется.

| Индекс | Элемент | Длина элемента |
| --- | --- | --- |
| 0 | `"Ахметов Ерлан"` | 13 |
| 1 | `"85"` | 2 |

Длина массива `parts.Length` равна **2**.

## 2. `int.TryParse` и `TryParseScores`

После `line.Split(';')` для строки `"Иванов Пётр;70;85;x"` получаем четыре части. В таблице показан отдельный вызов `int.TryParse(part, out int value)` для каждой из них.

| Индекс | Часть | Результат `TryParse` | Значение `out` |
| --- | --- | --- | --- |
| 0 | `"Иванов Пётр"` | `false` | `0` |
| 1 | `"70"` | `true` | `70` |
| 2 | `"85"` | `true` | `85` |
| 3 | `"x"` | `false` | `0` |

Если `TryParseScores` принимает первый элемент за ФИО и требует, чтобы все остальные элементы были целыми числами, метод вернёт **`false`**. Он начнёт разбор с индекса 1, успешно прочитает `70` и `85` и завершится с ошибкой разбора на `"x"`. Ноль в столбце `out` при `false` — значение, которое `int.TryParse` записывает при неудаче.

## 3. `s += i` и `StringBuilder.Append(i)`

Перед циклом `s` равна `""`, а `sb = new StringBuilder()` содержит пустой буфер. В таблице учтены выделения объектов `string` в .NET 8. Для `s += i` показаны случаи, когда строки для цифр `0`–`3` уже есть в кэше или ещё ни одна из них не закэширована.

| `i` | `s` после `s += i` | Новых `string`, если цифры в кэше | Новых `string`, если кэш цифр пуст | Содержимое `sb` после `Append(i)` | Новых `string` при `Append(i)` |
| --- | --- | --- | --- | --- | --- |
| 0 | `"0"` | 0 | 1 | `0` | 0 |
| 1 | `"01"` | 1 | 2 | `01` | 0 |
| 2 | `"012"` | 1 | 2 | `012` | 0 |
| 3 | `"0123"` | 1 | 2 | `0123` | 0 |
| **Итого** | | **3** | **7** | | **0** |

В `s` последовательно записываются четыре строковых результата. На первом шаге объединение с пустой строкой возвращает строку `"0"`, полученную при преобразовании числа. На следующих трёх шагах для результата объединения выделяется по новой строке. Преобразование каждого числа добавляет ещё одну строку, если её пока нет в кэше. Начальный литерал `""` в подсчёт выделений внутри цикла не входит.

`Append(int)` записывает цифры в буфер. Четыре цифры помещаются в начальную ёмкость, поэтому внутри цикла новых объектов нет. Перед циклом `new StringBuilder()` создаёт один объект `StringBuilder` и один массив `char[]`. Если после цикла вызвать `sb.ToString()`, появится одна строка `"0123"`.

## 4. Почему `s.ToUpper()` оставляет `s` прежней

Объекты `string` неизменяемы. `ToUpper()` возвращает строку в верхнем регистре. Чтобы сохранить результат в `s`, нужно присвоить его обратно.

```csharp
string s = "Ахметов Ерлан";
s.ToUpper();       // s по-прежнему содержит "Ахметов Ерлан"
s = s.ToUpper();   // теперь s содержит "АХМЕТОВ ЕРЛАН"
```
