# Трассировка операций с массивом

Исходный массив: `a = {4, 1, 7, 3, 9}`, длина `n = 5`. Индексы начинаются с 0. Каждый алгоритм ниже выполняется независимо над исходным массивом.

## 1. Циклический сдвиг влево на одну позицию

Сохраняем первый элемент в буфер, последовательно перемещаем элементы на одну позицию влево, затем записываем буфер в последнюю ячейку.

```csharp
int buffer = a[0];
for (int i = 0; i < n - 1; i++)
    a[i] = a[i + 1];
a[n - 1] = buffer;
```

| Шаг | i | Состояние массива после шага |
| --- | --- | --- |
| 0. Исходное состояние | — | `{4, 1, 7, 3, 9}` |
| 1. Сохранить `buffer = a[0] = 4` | — | `{4, 1, 7, 3, 9}` |
| 2. `a[0] = a[1]` | 0 | `{1, 1, 7, 3, 9}` |
| 3. `a[1] = a[2]` | 1 | `{1, 7, 7, 3, 9}` |
| 4. `a[2] = a[3]` | 2 | `{1, 7, 3, 3, 9}` |
| 5. `a[3] = a[4]` | 3 | `{1, 7, 3, 9, 9}` |
| 6. `a[4] = buffer` | — | `{1, 7, 3, 9, 4}` |

**Результат:** `{1, 7, 3, 9, 4}`.

## 2. Разворот массива на месте

Снова берём исходный массив `{4, 1, 7, 3, 9}`. Меняем местами элементы с симметричными индексами `i` и `n - 1 - i`.

```csharp
for (int i = 0; i < n / 2; i++)
{
    int temp = a[i];
    a[i] = a[n - 1 - i];
    a[n - 1 - i] = temp;
}
```

| Шаг | i | Действие | Состояние массива после шага |
| --- | --- | --- | --- |
| 0 | — | Исходное состояние | `{4, 1, 7, 3, 9}` |
| 1 | 0 | Обмен `a[0]` и `a[4]` (4 и 9) | `{9, 1, 7, 3, 4}` |
| 2 | 1 | Обмен `a[1]` и `a[3]` (1 и 3) | `{9, 3, 7, 1, 4}` |

**Результат:** `{9, 3, 7, 1, 4}`. Выполнено **2 обмена**.

В целочисленном делении `n / 2 = 5 / 2 = 2`, поэтому цикл выполняется для `i = 0` и `i = 1` (условие `i < n / 2`). Каждую симметричную пару нужно обменять ровно один раз. Если продолжить цикл через весь массив, пары будут обменены повторно, и массив вернётся к исходному порядку. При нечётной длине центральный элемент `a[2] = 7` остаётся на месте и обмена не требует.

## 3. Ошибка при начальном значении min = 0

Пусть `min` хранит значение минимального элемента, а алгоритм обновляет его, когда `a[i] < min`.

Контрпример — сам исходный массив `{4, 1, 7, 3, 9}`: все элементы положительные, поэтому ни один из них не меньше 0. Переменная `min` останется равной **0**, хотя правильный минимум — **1**, и нуля в массиве нет.

Для непустого массива начальное значение нужно брать из первого элемента: **`min = a[0]`**. Просмотр остальных элементов начинается с индекса 1.

```csharp
static int FindMin(int[] a)
{
    if (a == null || a.Length == 0)
        throw new System.ArgumentException("Массив должен быть непустым.");

    int min = a[0];
    for (int i = 1; i < a.Length; i++)
    {
        if (a[i] < min)
            min = a[i];
    }
    return min;
}
```

Для исходного массива значение `min` меняется с 4 на 1 и далее остаётся равным 1. У пустого массива минимального элемента нет, поэтому его нужно обработать отдельно.
