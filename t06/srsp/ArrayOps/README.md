# ArrayOps

Четыре метода класса `ArrayOps` реализованы без LINQ, `Array.Reverse` и `Math.Min`. Индексы начинаются с 0. Начальное значение минимума берётся из `a[0]`; строгое сравнение сохраняет индекс первого минимального элемента. Разворот изменяет исходный массив и использует одну временную переменную.

Запуск из каталога проекта при установленном .NET SDK 8 или новее:

```text
dotnet run
```

Ожидаемые результаты при `x = 2`:

| Исходный массив | Sum | IndexOfMin | CountGreater | После Reverse |
| --- | ---: | ---: | ---: | --- |
| {4, 1, 7, 3, 9} | 24 | 1 | 4 | {9, 3, 7, 1, 4} |
| {5} | 5 | 0 | 1 | {5} |
| {-2, -7, -4} | -13 | 1 | 0 | {-4, -7, -2} |
| {2, 2, 2} | 6 | 0 | 0 | {2, 2, 2} |

Для пустого массива `Sum` и `CountGreater` возвращают 0, `Reverse` ничего не меняет, а `IndexOfMin` выбрасывает `ArgumentException`. Все методы отклоняют `null`. При переполнении суммы выбрасывается `OverflowException`.
